One line of office comedy, under 200 characters, for the Office Joke Open. The program writes the joke to /output/entry.txt and an AI judge compares the field head to head for the single funniest line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
